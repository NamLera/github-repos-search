# Поиск репозиториев GitHub

Возможности
Поиск репозиториев GitHub.
Автодополнение с отображением 5 результатов поиска.
Использование Debounce для уменьшения количества запросов к серверу.
Добавление выбранных репозиториев в список.
Удаление репозиториев из списка.

Используемые технологии:
HTML
CSS
JavaScript
Fetch API
DOM
Debounce
